# Security Policy

## Supported Versions

The initial release is provided as a standalone JavaScript script.

| Version | Supported |
| --- | --- |
| 1.0.x | Yes |

## Reporting a Security Issue

Please do not publish credentials, Discord tokens, cookies, passwords, or other sensitive information in a public issue.

For security-sensitive reports, use a private GitHub security report if available for the repository.

## User Safety

DiscordQuestPilot does not require users to provide their Discord password or authentication token.

Never request or share:

- Discord authentication tokens
- Passwords
- Session cookies
- API keys
- Private account information

Always review source changes before executing a new release.

## Scope

This policy covers security issues in the DiscordQuestPilot source code. Compatibility problems caused by changes to Discord's internal client are considered maintenance/compatibility issues rather than security vulnerabilities.
